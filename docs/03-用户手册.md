# Midscene AI 自动化测试平台 — 用户手册

**版本**：1.0  
**更新日期**：2026-02-13  

---

## 1. 产品简介

Midscene AI 自动化测试平台是一个基于 AI 的自动化测试工作流系统，帮助测试人员：

1. 用 Excel 维护测试用例
2. 由 AI 自动将用例步骤转换为可执行的 Midscene YAML 脚本
3. 批量执行脚本并实时查看进度与日志
4. 在报告中心查看通过率、失败原因与截图

整体流程：**上传 Excel 测试用例 → AI 自动生成脚本 → 批量执行自动化测试 → 查看报告与分析结果**。

## 2. 功能入口与导航

- **侧边栏**：工作流配置、执行监控、报表中心
- **顶部栏**：全局搜索（⌘K）、消息通知、用户信息
- **面包屑**：当前所在页面路径

## 3. 工作流配置

### 3.1 上传测试用例

- 支持 **Excel** 格式（.xlsx、.xls）
- 系统会自动识别表格中的：用例编号、标题、描述、前置条件、操作步骤、预期结果、优先级（支持中英文列名）
- 可一次上传多个用例，批量解析并保存

### 3.2 AI 生成脚本

- 选择要生成脚本的用例后，点击生成
- 使用 **DeepSeek** 将人工编写的测试步骤转为 Midscene YAML 脚本，每个用例对应一个脚本
- **可选**：上传「示例 Excel + 对应 YAML」供 AI 参考格式与风格；不传则使用系统默认示例
- 支持对生成结果不满意时重新生成

### 3.3 脚本查看与编辑

- 以列表形式展示所有已生成脚本，点击可查看详情
- 脚本以代码形式展示，带语法高亮
- 可在脚本详情页编辑 YAML 内容并保存

### 3.5 传统视觉比对（降低视觉 token 消耗）

- 对于“根据图片/封面寻找特定电视剧”这类任务，建议在 `flow` 中使用 `traditionalVisionAssert`
- 该步骤会使用本地传统视觉模型做图像比对，不把截图发给视觉大模型做比对
- 常规操作步骤（如 `ai` 导航）仍可继续使用大模型判断与执行
- 参考图库放置位置：`backend/vision_models/references/tv_series/`
- 传统视觉实现替换入口：`backend/workflow/services/traditional_vision_matcher.py`
- 系统支持自动分流：即使仍写 `aiAssert`，在识别到“找电视剧/封面匹配”类语义时，也会自动切换到传统视觉比对

### 3.4 重新生成

- 若对某批脚本不满意，可重新选择用例并执行生成，会覆盖原有脚本

## 4. 执行监控中心

### 4.1 启动执行

- 进入执行监控页面后，可自动或手动启动当前批次的测试执行
- 可选择性执行部分用例或全部用例

### 4.2 进度与统计

- **整体进度**：以百分比显示当前批次执行进度
- **统计面板**：总任务数、运行中、已通过、失败数

### 4.3 实时日志

- 通过 **SSE** 实时接收执行日志，在页面上持续刷新显示

### 4.4 测试队列

- 显示当前正在运行和等待中的测试用例，便于了解执行顺序与状态

### 4.5 停止与重跑

- 执行过程中可随时点击「停止」中断测试
- 执行结束或中断后，可点击「重新运行」再次执行

### 4.6 完成跳转

- 测试全部完成后，可自动跳转到报告中心查看结果

---

## 5. 测试报告中心

### 5.1 执行概览

- 总用例数、通过率、通过数、失败数

### 5.2 报告列表

- 列表展示每次执行的测试结果，包括：用例编号、名称、描述、执行时间、耗时、状态（通过/失败/执行中/等待中）
- 支持按用例编号、名称或状态筛选

### 5.3 详情查看

- 点击某条记录可查看：
  - 执行状态与结果
  - 失败原因说明（若有）
  - 执行日志
  - 执行截图（若有）
  - 时间信息

### 5.4 其他操作

- **刷新报告**：手动拉取最新数据
- **运行新测试**：返回工作流配置页，开始新一轮测试

---

## 6. 使用流程简要说明

1. **准备**：将测试用例整理到 Excel 中（含编号、标题、步骤、预期结果等）
2. **配置**：在工作流配置页上传 Excel，选择用例并生成脚本（可上传示例以规范风格）
3. **执行**：进入执行监控页启动执行，观察进度与实时日志，必要时停止或重跑
4. **分析**：在报告中心查看通过率、失败用例、日志与截图，定位问题后可在工作流配置中调整用例或脚本再执行

---

## 7. 注意事项

- Excel 列名可为中文或英文，系统会尝试自动匹配常见列名
- AI 生成依赖网络与 API 配置，若生成失败请检查网络与后端配置（见部署文档）
- 执行自动化测试前请确保 Midscene 运行环境与设备（如 Android 设备/模拟器）已就绪
- 系统设置、本地报告导出等功能入口已预留，当前版本尚未开放
