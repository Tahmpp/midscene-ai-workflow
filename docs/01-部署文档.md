# Midscene AI 自动化测试平台 — 部署文档

**版本**：1.0  
**更新日期**：2026-02-13  

---

## 1. 项目概述

本系统为前后端分离架构：

- **后端**：Django 6.x + Django REST framework，提供 REST API 与 SSE 实时日志流
- **前端**：React 19 + Vite 6，通过 API 与后端交互
- **数据库**：MySQL
- **AI 脚本生成**：DeepSeek（通过火山引擎等兼容 OpenAI 的 API）
- **测试执行**：基于 Midscene-Python 执行 YAML 脚本（Android 设备/模拟器）

---

## 2. 环境要求

| 项目 | 要求 |

## 3. 后端部署

### 3.1 创建虚拟环境并安装依赖

```bash
cd midscene-ai-workflow
python -m venv venv
# Windows
venv\Scripts\activate
# Linux/macOS
source venv/bin/activate

pip install django djangorestframework django-cors-headers pymysql python-dotenv pandas openai
```

若项目根目录或 `backend` 下已有 `requirements.txt`，可使用：

```bash
pip install -r requirements.txt
```

### 3.2 数据库准备

1. 在 MySQL 中创建数据库（名称与 `.env` 中 `DB_NAME` 一致，默认 `midscene_workflow`）：

```sql
CREATE DATABASE midscene_workflow CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
```

2. 配置后端环境变量（在 `backend` 目录下创建或编辑 `.env`，或使用项目根目录 `.env`）：

```env
DB_NAME=midscene_workflow
DB_USER=root
DB_PASSWORD=你的密码
DB_HOST=localhost
DB_PORT=3306

DJANGO_SECRET_KEY=你的随机密钥

# AI 脚本生成（DeepSeek，火山引擎等）
VOLCENGINE_API_KEY=你的API密钥
VOLCENGINE_API_BASE_URL=你的API地址
GENERATION_MODEL_NAME=deepseek-v3-2-251201
```

### 3.3 迁移与启动

```bash
cd backend
python manage.py migrate
python manage.py runserver 0.0.0.0:8000
```

后端默认运行在 **http://localhost:8000**，API 前缀为 **/api/**。

## 4. 前端部署

### 4.1 安装依赖与开发运行

```bash
cd midscene-ai-workflow
npm install
npm run dev
```

前端开发服务器默认运行在 **http://localhost:5173**。需在 frontend 或环境变量中配置后端 API 基地址（如 `http://localhost:8000/api`）。

### 4.2 生产构建

```bash
npm run build
```

构建产物在 `dist/`。使用 Nginx、IIS 等将站点根目录指向 `dist`，并配置反向代理将 `/api` 转发到后端 `http://localhost:8000`。

---

## 5. 生产部署要点

1. **ALLOWED_HOSTS**：在 `backend/backend/settings.py` 中设置实际域名或 IP，勿使用 `*`。
2. **DEBUG**：生产环境设置 `DEBUG=False`。
3. **SECRET_KEY**：使用环境变量 `DJANGO_SECRET_KEY`，且不要提交到版本库。
4. **CORS**：生产环境建议将 `CORS_ALLOW_ALL_ORIGINS` 改为白名单（如 `CORS_ALLOWED_ORIGINS`）。
5. **静态/媒体**：生产环境使用 `python manage.py collectstatic` 并配置 Web 服务器托管静态与媒体文件；报告等文件存放在 `backend/reports` 或 `MEDIA_ROOT` 下时，需保证目录可写与访问权限。

## 7. 常见问题

- **数据库连接失败**：检查 MySQL 已启动、`.env` 中 `DB_*` 正确、数据库已创建。
- **AI 脚本生成失败**：检查 `VOLCENGINE_API_KEY`、`VOLCENGINE_API_BASE_URL` 及网络可达性。
- **前端请求 404 / CORS 错误**：确认后端已启动、前端请求的 baseURL 为 `http://localhost:8000/api`，并检查 CORS 配置。
